# Quran Keluarga

Native Android prototype for a calm, ad-free Quran reading app centered on shared family reading progress.

## Stack

- Kotlin
- Jetpack Compose
- Material 3
- Gradle Kotlin DSL

## Run

```bash
./gradlew assembleDebug
```

Debug APK output:

```text
app/build/outputs/apk/debug/app-debug.apk
```
